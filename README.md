# 🚗 Automobile - Pixel-Perfect Responsive Website Clone
A pixel-perfect, fully responsive frontend clone of the Antixor Automobile dealership design. Hand-coded entirely from scratch to showcase advanced CSS Grid/Flexbox layouts.

## 🚀 Live Demo
[View the Live Project Here](https://jayles08.github.io/antixor-automobile-clone/)

> ### ⚠️ Work in Progress / Project Status
> Please note that this repository is currently a **Work in Progress (WIP)**. While core layouts and structures are in place, some responsive refinements, active states, and sections are still being fine-tuned to match the design perfectly.

A high-fidelity, **pixel-perfect**, and **fully responsive** frontend implementation of a modern automobile dealership web platform. 

💡 **Note on Development:** This entire codebase was written and translated **completely from scratch by myself**. No external design-to-code builders, template injectors, or automated generation tools were used—just pure, manual translation of the visual mockup into precise, semantic code.

## ✨ Features

*   **Hand-Coded From Scratch:** Developed entirely line-by-line to ensure total layout control, zero code bloat, and highly semantic markup.
*   **Pixel-Perfect Execution:** Every padding, margin, font size, and color hex matches the original Antixor design specifications exactly.
*   **Fully Responsive Architecture:** Adapts flawlessly across a wide range of viewports, including:
    *   🖥️ Wide Desktop Screens (1440px+)
    *   💻 Laptops & Tablets (768px - 1024px)
    *   📱 Mobile Devices (320px - 480px)
*   **Modern CSS Layouts:** Heavy utilization of **CSS Flexbox** and **CSS Grid** for predictable layout control without breaking structures.
*   **Interactive UI:** Hover effects, smooth transitions on interactive cards, and functional form inputs.

*   **HTML5:** Semantic markup structure.

*   **JavaScript (ES6+):** For handling mobile navigation toggles, slider functionality, and interactive states.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites
You only need a modern web browser to view this project.

### Installation & Setup

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```

2. Navigate into the project directory:
   ```bash
   cd automobile-clone
   ```

3. Open the project:
   * Simply double-click `index.html` to open it in your default browser, or
   * Run it via an extension like **Live Server** in VS Code for live development reloading.

## 📱 Responsiveness Showcase

The project dynamically scales down to handle tighter viewport environments down to standard mobile sizing, condensing side-by-side elements into linear, highly readable column flows.

| Desktop Layout | Mobile Layout |
| :--- | :--- |
| Full-width grid sections | Stacked mobile card items |
| Side-by-side featured cars | Single-column scrollable feed |
| Horizontal navigation header | Mobile hamburger drop-down menu |
